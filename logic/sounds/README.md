# Sound effects

Put short `.wav` files here. The game plays them when something happens:

| File | When |
|------|------|
| `stern.wav` | A star is collected |
| `kristall.wav` | An energy crystal is collected |
| `alien.wav` | A frozen alien is caught |
| `treffer.wav` | The robot gets hit |
| `gameover.wav` | Game over |
| `level.wav` | A new level starts |

Missing files are skipped. The volume is set by `EFFEKT_LAUTSTAERKE` (0.0–1.0) at the top of `logic/logic.py`.

Only add sounds you made yourself or have a license for.
