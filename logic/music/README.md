# Music

Put background music files here (`.mp3`, `.wav`, `.ogg` or `.m4a`).
All files in this folder play in a loop, in alphabetical order, once the game starts.

The volume is set by `MUSIK_LAUTSTAERKE` (0–100) at the top of `logic/logic.py`.
Without files the game simply runs without music.

Only add music you made yourself or have a license for.
